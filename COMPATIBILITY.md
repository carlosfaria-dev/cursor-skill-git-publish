# Compatibility notes

Quick reference for install paths. Prefer the README for full instructions.

| Tool | Supported | Install directory for this skill folder |
|------|-----------|-----------------------------------------|
| Cursor | Yes | `~/.cursor/skills/git-publish-projects/` or `.cursor/skills/git-publish-projects/` |
| Google Antigravity | Yes | `.agents/skills/git-publish-projects/` or `~/.gemini/config/skills/git-publish-projects/` |
| Claude Code | Yes (SKILL.md format) | `~/.claude/skills/` or `.claude/skills/` |
| OpenAI Codex | Yes (SKILL.md format) | `~/.codex/skills/` or `.agents/skills/` |
| GitHub Copilot | Not as native Agent Skill | Do not expect auto-discovery of `SKILL.md` |
